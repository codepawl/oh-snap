# Security

oh-snap takes over your screenshot keys and updates itself, so security reports matter to us.

## Report a problem

Report a security problem privately on GitHub: open the **Security** tab of this repository and pick **Report a vulnerability**. Do not open a public issue for it.

We reply as soon as we can and say what we will do.

## What is in scope

- The update path: the download, the SHA-256 check against `SHA256SUMS.txt` and the swap of the program.
- The install scripts `install.ps1` and `install.sh`.
- The command socket on macOS and Linux, and `oh-snap://` links on Windows.
- Add-ons, which run as separate programs.

## Supported versions

Only the latest release gets fixes. oh-snap updates itself, so most users run the latest release.
